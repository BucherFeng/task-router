# v0.5 对话入口验证

最终安装版本：0.5.0+codex.20260914115844。日期：2026-09-14。

## 完成的入口整合

- 插件包含 MCP 服务、依赖启动器、后台进程入口和完整控制器，不再依赖仓库外部脚本。
- task_submit、task_status、task_wait、task_cancel、task_resume、router_diagnose
  由 Codex 加载，用户通过对话提出需求及操作任务。
- skill 已改为提交并收集工具结果，不要求用户输入终端命令、内部类型或任务编号。
- 启动器从已启用插件的 marketplace 和缓存版本定位自身，未硬编码作者机器路径。
- 后台 worker 独立于前台 MCP 连接；长结果支持分页，受管 worker 无法再调用任务 broker。
- 旧开发 CLI 保留兼容入口，实际运行代码已移入插件包。

## 自动化验证

全仓库 96 项测试通过，覆盖原有路由/控制器测试及新增 MCP 集成：

- 工具发现、提交、等待、查询与取消。
- 稳定请求键的重复提交不会重复执行。
- 成功任务恢复不会重新执行。
- 前台 MCP 连接结束后，后台继续执行，并可通过新连接查询结果。
- 模拟部分修改后的失败，由后台控制器选择下一候选继续。
- 整个插件复制到独立目录后，不依赖仓库 scripts 目录也能完成任务。
- 写入/超时参数严格校验，受管 worker 的 broker 工具为空。
- 插件启动路径定位、路径穿越拒绝、现有 SDK 复用、长结果分页。
- 安装缺少运行文件或配置损坏时明确失败，升级保留个人配置。

官方 skill 和 plugin 结构校验通过。结构与模拟测试不等于所有模型的实际可用性验证。

## Codex 原生加载验证

通过独立 app-server 的 thread/start 和 mcpServerStatus/list 检查安装后的插件，
返回 task-router@personal，runtimeStatus 为 connected、toolsError 为 null，
6 个工具均被发现。通过 mcpServer/tool/call 实际调用诊断和任务提交成功。

测试中关闭了该隔离 app-server 的无关 apps 连接，以免远程目录请求干扰本地
插件验证；没有修改用户全局 apps 或审批配置。

## 真实对话验证

在隔离目录向前台 glm-5.3-flash 发出自然语言请求：使用 task-router 创建
chat-hello.txt，内容为 routed-chat 和一个换行，只修改该文件。

实际观察到前台调用 task_submit，然后调用 task_wait 收集进度；后台控制器
选择 glm-5.3-flash/low，任务成功，前台最终汇报完成。独立检查确认文件内容
完全匹配，后台变化记录只包含 chat-hello.txt。

Codex 对有副作用的 MCP 工具请求授权。最初的测试客户端没有处理授权而拒绝
了调用；正确模拟本次已授权的隔离文件操作确认后，完整对话路径通过。插件
没有绕过授权，真实用户可在 Codex 界面确认，无需终端操作。

另一个原生工具测试在提交后关闭前台连接，真实后台任务仍完成 hello.txt。
再次提交相同请求键返回已有成功任务，没有新增执行尝试。

这些 MCP 任务的 completion_verified 为 false：工具没有接受任意主机验证命令。
本次文件内容由测试程序独立核查，不把 worker 自述等同于程序内置验证通过。

## 安装与配置保留

已执行真实本机升级，Codex 列表确认最终版本启用。安装缓存中的 18 个运行文件
与源码匹配（manifest 按 JSON 语义比较）。个人路由配置和 personal marketplace
在升级前后的 SHA-256 一致，旧插件目录已由安装器备份。

分享包的默认普通讨论候选改为已经验证的 gpt-5.5 和 gpt-5.6-sol，已有个人
配置未被覆盖。本轮环境已有 MCP SDK 1.27.0，实际启动使用现有解释器；缺少
SDK 时的私有环境自动下载分支没有进行真实联网安装实验。

## 仍然存在的边界

- 主模型仍需理解并提交请求，提交前失效的请求无法由后台恢复。
- 用户需启用插件，并在安装/升级后让新对话加载工具；不保证所有消息都强制路由。
- 运行时仍需要 Python 3.11+、可用的 Codex CLI 和模型凭据。
- 持久化模型冷却、余额查询、任意已有线程的透明恢复尚未实现。
- unknown 执行不会被自动重放；有界文件摘要不是完整回滚或外部操作幂等保证。
- 兼容性验证限于本机 Linux、Codex CLI 0.154.0，其他系统与版本需继续验证。

机器可读证据见 [验证数据](v0.5-validation.json)。
